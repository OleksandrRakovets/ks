## Why

Phone-portrait-first, one-finger use at the billiards table. The existing pages were functional but felt like a debug tool, not a club app.

## Design decisions made

- Dark by default (Catppuccin Mocha), explicit Latte light, auto via `prefers-color-scheme`.
  CSS-only approach: `.dark` / `.latte` classes on `<html>`, set via cookie from `/api/theme`.
- Persistent green header (`--ctp-green`) with burger menu; back-arrow navigation via `handle.headerConfig`.
- Bottom tab bar (Control / Protocol) on the match page — `mt-auto` pushes it to viewport bottom.
- `primary?: boolean` / `secondary?: boolean` on `GameCommandPresetSchema` — game definition owns button prominence, renderer just reads flags.
  - Primary actions: `py-4 text-base font-medium` (large tap target)
  - Secondary actions: hidden behind `··· Більше` toggle, `py-2 text-sm`
- Actor-paired commands (same commandType, A + B actors) render in a 2-column grid; single-actor commands get their column with a `<div />` placeholder.
- No Card wrappers inside renderers — flat `div.grid gap-4` only.
